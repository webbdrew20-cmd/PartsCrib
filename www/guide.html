PartsCribSetup and usage guide

Parts Crib keeps track of what is on the shelves across your maintenance areas — what it is, which bin it lives in, how many are left, and who took the last one.

It runs on one ordinary Windows PC. Everyone else opens it in a web browser, including phones on the shop wifi. There is nothing to install on anybody's machine, no database to set up and no monthly fee.

1. What is actually in the folder

PartsCrib.exe     the program — this is the whole thing
www\              the screens people see
inventory\        the data: parts, accounts, the movement log

PartsCrib.exe is a small web server, about 5 MB. It does not install anything, does not touch the registry, and needs no administrator rights to run. Deleting the folder removes it completely.

Everything lives in that folder Back up inventory\ and you have backed up the crib. Copy the folder to another machine and it works there, exactly as it was.
The parts list starts empty Four starter areas come set up — Tool Room, Maintenance Cage, Pump Room, Compressor Room — as examples. Rename, remove or add to them from Settings → Storage areas to match your own shop before you start adding parts.

2. Trying it on one computer first

Before committing to a server, run it on any PC to see what it does. Nothing is permanent and nothing is shared yet.

  1. Copy the folder to the computer Somewhere simple like C:\PartsCrib\. Use the local disk, not a network drive.
  2. Double-click PartsCrib.exe A black window appears for a second and hides itself, then the crib opens full screen with no address bar.
  3. Sign in User name MaintAdmin, with the temporary password that came with this installation. It isn't printed here on purpose — the app won't let you do anything else until you replace it.
  4. Have a look round Add a part, check it out, check it back in.
  5. Close it Press Alt+F4. The program shuts itself down about half a minute later. Your changes are already saved.
Windows may warn you the first time "Windows protected your PC" appears for any program that has not been through commercial code signing. Click More info, then Run anyway.

3. Putting it on the server for everybody

Do not put it on a shared drive and let everyone run it That is the obvious approach and it quietly destroys data. Each person would launch their own copy, and all of them would write the same file. Two people check parts out at the same moment and the second save wipes the first — no error, no warning, just a wrong number.

One computer runs the program. Everybody else gets a shortcut to a web address.

The machine does not need to be a real server. Any PC that stays switched on will do, as long as people can reach it by name on the network.

  1. Copy the folder to the server's local disk C:\PartsCrib\. Not a mapped drive, not a \\server\share path — a local disk avoids a whole category of file-locking problems.
  2. Start it in shared mode Open a command prompt in that folder and run: 
    C:\PartsCrib\PartsCrib.exe -shared
    It prints the addresses to hand out and stays running. This mode does not open a browser and the window stays visible on purpose.
  3. Let it through the firewall Once, in an administrator command prompt: 
    netsh advfirewall firewall add rule name="Parts Crib" ^
  dir=in action=allow protocol=TCP localport=8787
    This is the only step that needs administrator rights.
  4. Make it start by itself after a reboot In Task Scheduler, create one task:
    • Trigger: At startup
    • Action: start C:\PartsCrib\PartsCrib.exe, arguments -shared, starting in C:\PartsCrib
    • Tick Run whether user is logged on or not
    • Untick Stop the task if it runs longer than… — it is meant to run forever
  5. Give everyone the shortcut Parts Crib.url is in the folder. Open it in Notepad, change SERVERNAME to the server's real name, and put it in C:\Users\Public\Desktop on each machine, or push it out with Group Policy. 
    [InternetShortcut]
URL=http://SERVERNAME:8787/
    Use the computer's name rather than its IP address, so a network change does not break every shortcut at once.

Phones and tablets on the shop wifi work too — same address, typed into any browser. No app to install.

4. Setting up who can use it

Nobody can see anything without signing in. There are two kinds of account.

TechLook parts up, see where they live, check them out, check them back in, and flag uncounted things for ordering.
AdministratorAll of that, plus adding and editing parts, changing settings, reading the movement log, and managing accounts.
  1. Sign in as MaintAdmin and replace the password It will not let you do anything else until you do.
  2. Add a person for each tech Settings → People → Add a person. Give each one a temporary password and tell them what it is.
  3. They replace it themselves The first time they sign in they are made to choose their own. Nobody but them ever knows their real password — not even you. Anyone still holding a temporary one is marked Temporary in the list.

If somebody forgets theirs, open their entry in Settings and type a new temporary password. That signs them out everywhere and puts them back through the same prompt. You never need to know what they pick.

5. Using it day to day

Finding something

Type into the search box at the top. It matches the name, the part number, the bin label, the notes and any keywords — so 6205 bearing and pump seal both work, in either word order. The area buttons underneath narrow it to one room.

Taking a part

Tap Check out on the row for one. For more than one, tap the part itself, set the number, then Check out. Every movement is recorded against the account that made it.

Putting one back

Open the part and tap Check in. It will not let the count go above the level an administrator stocked — if the shelf holds twelve, twelve is the most that can ever be on it. The button says Room for 2 or All 12 are in rather than letting somebody tap and get an error.

When a shipment arrives

That is not a check-in, it is a new stock level. Open the part, tap the pencil to edit it, and type the new number into On hand. Administrators only. This keeps the movement log honest: a check-in of fourteen should mean fourteen parts came back from the floor.

Things nobody counts

Bolts, batteries, zip ties. Turn off Watch the count on this part when adding them and they show a location but no number. Since nothing can notice they are running out, they get an Order more button instead — anyone can tap it, the part turns amber and joins the reorder list, and whoever puts the new box away clears it.

Where things live

A label reads MC-1-2-7 — maintenance cage, bin 1, row 2, column 7. For a pallet or a drum sitting on the floor of a room, tick No designated placement and it reads PR - no designated section instead, which tells a tech the room without sending them hunting for a shelf that does not exist.

6. What the colours mean

Red Out of stock. None left. Sorted to the top of every list.
Amber Reorder. At or below the level set for that part, or flagged by hand for something uncounted.
Green Fine. Nothing to do.
Grey Not counted, and nobody has asked for more.

The word next to the label says the same thing, so nothing depends on being able to tell the colours apart. The Needs attention button at the top shows everything red or amber in one list — that is your ordering list.

7. Backups and records

  • Every change is written immediately to inventory\parts.json, and the previous version is kept as parts.bak.
  • The first change each day snapshots the whole file into inventory\backups\. The last thirty days are kept.
  • The movement log is inventory\log.csv — every checkout, check-in, edit and deletion, with the date and the account that did it. Download it from Settings and open it in Excel.
  • The parts list exports to CSV from Settings as well, for counting sheets or purchase orders.

Point the normal server backup at C:\PartsCrib\ and everything above is covered.

8. Where the line is

Signing in stops a coworker deleting parts, fudging a count, or checking in stock that never existed, and it puts a name against every movement. That is what it is for.
